# EXEC-OVERVIEW.md — Sentinal Systems UK

*Website-facing summary. The short, public version of the doctrine.*

---

**Sentinal Systems UK is a sovereign engineering house building
deterministic world-engines, intelligence systems, and operator-aligned
cognition substrates.**

Every Sentinal product shares one architecture: a sovereign runtime
spine that works fully disconnected, a declared integration surface for
external capability, operator policy above both, and hybrid execution
between them. Local-first in identity. Integration-native in capability.

**The flagship** — OSINT Sentinal Workstation — is a programmable
world-engine: a multi-plane hardware substrate (I/O, CPU workers and
WASM SIMD, GPU compute, rendering, orchestration) driving a Cesium
cockpit with dozens of live intelligence modules, terrain analysis, and
an SDK that lets external systems — agents, pipelines, engines — act
inside a shared world-state. Its hosted globe is the open playground:
every module and compute capability free to any browser.

**The ethos:** determinism over guesswork, modularity over monoliths,
locality over externality, operator supremacy — and sovereign
interoperability: the cloud is a tool we can use, never a foundation
we need.

**The posture:** we choose constraints worth breaking. The stated goal
is the best world-engine ever built on consumer hardware — and every
experiment lands as reusable substrate, so the platform compounds.
Bold targets, boring releases, measured claims.

Sentinal is a system — a sovereign substrate for engineered cognition
that extends wherever the operator points it.
