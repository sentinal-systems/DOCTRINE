# FOUNDATION-YEAR.md

## The First 12 Months of Sentinal Systems

**February 2026 → October 2026**

## Overview

Sentinal Systems began as a solo-developer experiment in February/March
2026. Within twelve months, it evolved into a multi-product, multi-plane,
cross-platform software company with a sovereign offline AI spine, a
deterministic compute architecture, and four independent product lines.

This document records the foundational year.

## Timeline Summary

### Month 1–2 — Learning to Code

- First line of code written in early 2026.
- Rapid transition from syntax → architecture.
- Early experiments in Node, Electron, and renderer isolation.
- Initial HAL plane concept emerges.

### Month 3–4 — The Sovereign AI Spine

- Offline AI system created (Astra-6 style).
- CLIP + Qwen Vision + Qwen Coder 7B integrated.
- Tool-call layer built.
- Deterministic orchestration rules established.
- This becomes **Sentinal Core**, the company's intelligence layer.

### Month 5–6 — Terrain & Tiles Pipeline

- DEM ingestion pipeline built.
- Local tile slicing + serving implemented.
- Zero-AI, deterministic transforms.
- Runs on a 2-core, 2GB RAM, 90GB SSD VPS.
- This becomes the backbone of all spatial products.

### Month 7–8 — OSINT Sentinal Workstation

Built in 7–8 weeks.

- Electron shell (optional).
- Node service platform (real product).
- HAL planes fully implemented.
- Worker-thread compute.
- Hosted mode + desktop mode.
- XR-ready renderer surfaces.
- Multi-user API server.
- Cross-platform builds (Mac, Win10, Win11, Web).
- Sovereign, offline-capable, deterministic.

This becomes **Product Line #1**.

### Month 8 — Sentinal Web Globe

Built in parallel with workstation.

- Browser-first renderer surface.
- Same DEM/tiles pipeline.
- Same API server.
- Same HAL orchestration.
- Zero Electron.
- Unlimited viewer scalability.
- Runs on the same tiny VPS.

This becomes **Product Line #2**.

### Month 9 — NameGuard

- Independent SaaS product.
- Namespace collision detection.
- Semantic matching.
- Offline inference via Sentinal Core.
- Fully hosted, fully sovereign.

This becomes **Product Line #3**.

### Month 10 — Sentinal-Sound (RTX Visualiser)

- DSP chain + WASAPI loopback.
- Multi-stage gating.
- Deterministic timing.
- DX12U renderer.
- RTX-paced visualiser.
- Creative + technical vertical.

This becomes **Product Line #4**.
